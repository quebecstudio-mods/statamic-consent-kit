# Changelog

## 6.0.1 - 2026-09-24

### Changed

- The English control panel follows one casing rule, shared with the Craft CMS
  plugin and with both hosts: title case for labels, titles, headings and
  column names, sentence case for permissions, buttons, links and options. The
  permissions, the export and filter buttons and the listing options were
  titled as if they were labels.
